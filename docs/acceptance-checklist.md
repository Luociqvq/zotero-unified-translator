## B. 划词即时翻译（核心）

| # | 步骤 | 判定标准 | 结果 | 备注 |
|---|---|---|---|---|
| B1 | 打开一篇**带文本层**的 PDF，鼠标拖选一句话 | 弹出 ZUT 面板，先显示"翻译中 · 0.0s"与加载动画 | | |
| B2 | 观察面板位置 | 面板停靠在 Zotero **原生批注栏正下方**，左边缘与批注栏对齐；**没有**被塞进那条窄栏里 | | |
| B3 | 等待返回 | 显示译文，状态行显示"完成 · 模型名 · N.Ns" | | |
| B4 | 滚动 PDF 页面 | 面板跟随批注栏移动；批注栏滚出可视区时面板自动关闭 | | |
| B5 | 点击页面其他位置 | 面板关闭 | | |
| B6 | 按 Esc | 面板关闭 | | |
| B7 | 选中同一句话再翻译一次 | 状态显示"使用缓存"，返回明显更快 | | |
| B8 | 切换目标语言（如 简体中文 → 繁体中文）后翻译同一句 | 输出确实变为繁体，**不是**简体 | | |

| B10 | 选一段超过上限的文本（OpenAI 兼容约 12000 字符 / Google 约 4500 字符） | 给出明确报错，不是静默失败 | | |

## F. 整篇 PDF 翻译（需后端）

前置：后端已启动，`/api/v1/health` 可访问，`pdf2zh-next` 引擎可用。

| # | 步骤 | 判定标准 | 结果 | 备注 |
|---|---|---|---|---|
| F1 | 选一篇较短、有文本层的 PDF 的父条目 → 右键 `ZUT → ZUT: 翻译 PDF` | 出现进度通知，依次显示读取/上传/排队/翻译/下载/导入 | | |
| F2 | 等待完成 | 父条目下新增一个 PDF 附件，**原 PDF 未被替换** | | |
| F3 | 打开译文检查 | 文字可读，段落/双栏/表格/公式版式基本合理 | | |
| F4 | 译文附件标题 | 含原文件名、语言、输出模式、引擎与源文件哈希片段 | | |
| F5 | 对同一文献再翻译一次 | 提示已有相同译文，**不重复导入** | | |
| F6 | 换「仅译文 PDF」输出模式再翻译 | 输出为纯译文，无原文对照 | | |
| F7 | 在 PDF 阅读器页面/选中文字上右键 | 出现「翻译整篇 PDF」并可用 | | |
| F8 | 文献列表选中**两个**条目后右键 | 整篇翻译入口不可用或提示只支持单篇（这是预期限制） | | |
| F9 | 上传时把 Token 改错 | 后端返回 401，插件显示明确错误 | | |
| F10 | 停掉 Worker 后提交任务 | 任务停在排队；插件报错说明 Worker 不可用（API 在线 ≠ Worker 在线） | | |
| F11 | 翻译进行中关闭 Zotero 再打开 | 不会自动接续下载（当前已知限制，确认行为符合预期） | | |
