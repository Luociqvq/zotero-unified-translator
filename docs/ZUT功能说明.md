# Zotero Unified Translator（ZUT）插件功能说明

版本：0.1.8  
适用宿主：Zotero 10.0.x  
作者：Luoci

## 1. 插件定位

Zotero Unified Translator（简称 ZUT）是一个面向 Zotero PDF 阅读流程的翻译插件，提供两类能力：

1. 即时翻译：在 Zotero PDF Reader 中选中文字后，直接显示译文。
2. 整篇 PDF 翻译：把整篇 PDF 提交到独立的 ZUT 后端，由 `pdf2zh-next` 处理并返回双语 PDF 或仅译文 PDF。

两类翻译使用不同的接口和配置。即时翻译接口负责短文本请求；整篇 PDF 后端负责文件上传、任务排队、PDF 处理、译文生成和结果下载。

## 2. 功能总览

| 功能 | 说明 |
|---|---|
| PDF 划词翻译 | 在 PDF Reader 中选中文字，使用当前即时翻译服务获得译文 |
| 译文复制 | 将即时翻译结果复制到剪贴板 |
| 保存为注释 | 将译文保存到当前 PDF 的选区注释；已有可编辑注释会追加内容并保留原评论 |
| 整篇 PDF 翻译 | 通过独立 ZUT 后端生成双语 PDF 或仅译文 PDF |
| PDF Reader 右键菜单 | 页面或选中文字右键可选择“翻译整篇 PDF” |
| 文献列表右键菜单 | 选中一个条目或 PDF 附件后，通过 `ZUT → ZUT: 翻译 PDF` 启动整篇翻译 |
| 双接口检查 | “检查两个接口”会同时检查即时翻译请求和整篇 PDF 后端，并分别显示结果 |
| 多语言目标 | 支持简体中文、繁体中文、英语、日语、韩语、德语、法语和西班牙语 |
| 进度通知 | 整篇翻译期间可显示读取、上传、排队、翻译、下载和导入进度 |
| 凭据保护 | API Key 和后端 Token 保存到 Zotero 凭据存储，不写入普通插件偏好 |

## 3. 安装和设置入口

1. 在 Zotero 中打开“工具 → 插件”。
2. 点击齿轮菜单，选择“从文件安装插件”。
3. 选择 `release/zotero-unified-translator.xpi`。
4. 按提示重启 Zotero。
5. 打开“编辑 → 设置”，在左侧选择“Zotero Unified Translator”。

插件管理器中的插件详情页只显示版本、作者和启用状态，不是功能配置页。所有接口、模型、密钥和整篇翻译选项都在 Zotero 主设置中的插件面板配置。

## 4. 即时翻译

### 4.1 支持的服务

插件提供两个即时翻译服务选项：

- `HY-MT1.5-1.8B 翻译接口（OpenAI 兼容）`：默认服务，使用 Chat Completions 协议。
- `Google Translate（免 Key）`：不需要 API Key，但属于 best-effort 服务。

默认 OpenAI 兼容配置为：

| 字段 | 默认值或填写方式 |
|---|---|
| 翻译接口地址 | `https://fanyi.eieu.cn/v1` |
| 模型名称 | `HY-MT1.5-1.8B` |
| API Key | 填写服务提供方发放的密钥 |
| 默认目标语言 | 简体中文 |

实际请求地址是在接口地址后追加 `/chat/completions`。如果使用其他 OpenAI 兼容服务，应填写该服务的基础地址和实际模型 ID。

### 4.2 使用步骤

1. 在设置中选择即时翻译服务和目标语言。
2. 填写接口地址、模型名称和 API Key。
3. 点击“保存设置”。保存后当前页面会保留输入框内容，方便确认密钥确实已提交。
4. 点击“测试即时翻译”，确认服务能够返回测试译文。
5. 打开一个有文本层的 PDF。
6. 在 PDF Reader 中拖选文字。
7. 在选区弹窗中查看译文，可复制译文或保存为注释。

如果重新打开设置页，密钥输入框不会回显已经保存的密钥；这是为了避免密钥长期显示在配置页面。输入框留空后再次保存会保留旧密钥，点击“清除”才会删除凭据。

### 4.3 限制

- Google Translate 单次选区最多约 4500 个字符。
- OpenAI 兼容服务单次选区最多约 12000 个字符。
- 即时翻译当前只处理 PDF Reader 中的可选文本，不包含扫描 PDF 的 OCR。

### 4.4 弹窗和速度

- 选区翻译弹窗采用响应式窄布局，最大宽度约 360px；较长译文会在结果区内换行并滚动，不再把弹窗横向撑出页面。
- 弹窗状态栏会显示本次请求耗时，便于区分网络、服务排队和模型推理造成的等待。
- 发送到 OpenAI 兼容接口前会合并 PDF 常见的换行、断词和软连字符，减少无意义输入长度。
- 同一服务、模型、目标语言和选区文本在内存中缓存 5 分钟，重复选中同一句时可以直接显示；缓存不会写入磁盘，重启 Zotero 后清空。
- 首次翻译耗时仍主要取决于远程服务的网络和模型推理速度。要进一步降低等待，需要使用更快的模型/服务，或由服务端提供流式返回。

## 5. 整篇 PDF 翻译

### 5.1 后端配置

整篇翻译不使用即时翻译接口，而是使用独立的 ZUT PDF 后端。可以连接远程 HTTPS 服务，也可以连接本机服务：

| 字段 | 说明 |
|---|---|
| 整篇翻译后端地址 | 例如 `https://pdf.example.com` 或 `http://127.0.0.1:8890` |
| 后端 Bearer Token | 与后端 `ZUT_AUTH_TOKEN` 保持一致；本机回环健康检查可不填 |
| PDF 引擎 | 当前为 `pdf2zh-next 2.9.0` |
| 输出模式 | 双语 PDF或仅译文 PDF |
| 显示进度通知 | 控制整篇翻译时是否显示 Zotero 进度窗口 |

后端内部还需要配置 LLM 地址、模型和 Key。这些 `ZUT_LLM_*` 配置属于服务器，不会自动读取插件的即时翻译 API Key。

### 5.2 检查两个接口

“检查两个接口”会并行执行两项检查：

1. 即时翻译接口：发送一条真实测试翻译请求，验证当前服务、模型和 API Key。
2. 整篇 PDF 接口：请求后端 `/api/v1/health`，验证服务状态以及当前选择的 PDF 引擎是否可用。

每个接口最多等待 15 秒；某个接口超时不会阻塞另一个接口的结果。结果会显示为三行：

```text
即时翻译接口：可用（HY-MT1.5-1.8B）
整篇 PDF 接口：可用（API 1 · pdf2zh_next）
整体检查：两个接口均正常
```

如果 API Key 未填写，即时翻译项会失败；如果后端地址、Token、引擎或服务状态异常，整篇 PDF 项会失败。整体结果只有在两项都成功时才会显示“两个接口均正常”。

### 5.3 启动整篇翻译

可以通过以下任一入口启动：

- Zotero 文献列表：选中一个父条目或一个 PDF 附件，右键选择 `ZUT → ZUT: 翻译 PDF`。
- Zotero PDF Reader：在页面空白处或选中文字后右键选择“翻译整篇 PDF”。

任务流程如下：

1. 读取 PDF 字节并计算源文件指纹。
2. 检查 ZUT 后端和所选 PDF 引擎。
3. 上传 PDF 并创建翻译任务。
4. 轮询任务状态和进度。
5. 下载生成的 PDF。
6. 将译文作为新的 Zotero 附件导入，原始 PDF 不会被覆盖。

对于有父条目的附件，译文会添加到同一个父条目下；同一父条目下相同标题的译文不会重复导入。

## 6. 菜单结构

插件右键菜单采用父菜单加子菜单的形式：

```text
文献列表右键
└─ ZUT
   └─ ZUT: 翻译 PDF

PDF Reader 右键
└─ 翻译整篇 PDF
```

文献列表中必须只选中一个条目或附件。整篇翻译是单篇操作，不支持一次选择多个文献批量提交。

## 7. 配置和数据安全

- 即时翻译 API Key 保存到 Zotero 的登录凭据管理器。
- 整篇 PDF 后端 Token 也保存到 Zotero 凭据管理器。
- 普通 Zotero 偏好只保存接口地址、模型名、目标语言和凭据引用，不保存密钥正文。
- 选中的文字会发送到当前即时翻译服务。
- 整篇 PDF 会发送到配置的 ZUT 后端，后端可能继续把翻译所需文本发送到其 LLM 服务。
- 插件没有自动同步密钥或遥测功能。
- 使用第三方翻译服务前，应确认其隐私、留存和计费政策。

## 8. 当前边界

- 暂不支持扫描 PDF OCR。
- 暂不支持批量翻译界面、逐句连续翻译、多服务并排对比和标题摘要翻译。
- 当前一次只提交一篇 PDF。
- PDF 双栏、复杂表格、公式和特殊字体的版式不能保证完全一致，需要人工检查译文。
- 没有插件内任务历史页；重启 Zotero 后不会自动接续未完成的下载。
- 真实翻译质量取决于后端 PDF 引擎、LLM 服务、模型权限、字体和网络。

## 9. 常见问题

### 设置中找不到插件

确认安装的是 0.1.8 XPI，重启 Zotero 后到“编辑 → 设置”左侧查找插件名称。插件详情页本身不会显示配置表单。

### 保存后 API Key 看起来没有保存

0.1.8 会在当前设置页保留输入框内容，并在状态区域提示已保存。重新打开设置页时为了安全不会回显密钥；此时留空并保存不会删除已保存的密钥。

### 即时翻译检查失败

检查即时服务地址是否包含 `/v1`、模型名称是否正确，以及 API Key 是否有效。点击“测试即时翻译”可以单独查看详细错误。

### 整篇 PDF 检查失败

检查后端地址是否指向 ZUT PDF 后端而不是即时翻译地址，确认 `/api/v1/health` 可访问、后端 Token 一致、Worker 正常运行且 `pdf2zh-next` 引擎可用。

### 翻译结果没有出现在 Zotero

保持 Zotero 打开直到任务完成，检查进度通知和后端日志。译文是新附件，不会替换原 PDF。

## 10. 验证状态

当前版本已完成 TypeScript 构建和插件回归测试。自动化测试覆盖插件启动注册、Reader 菜单、偏好页注册、凭据读写、PDF 二进制读写、后端下载来源校验和 XUL 标签。真实 Zotero 图形界面操作、真实 API Key、真实 PDF 翻译质量和复杂 PDF 版式仍需要用户在本机验收。
