# 安装 Zotero Unified Translator 1.0.1

1. 打开 Zotero 10.0.1。
2. 工具 → 插件 → 齿轮 → 从文件安装插件。
3. 选择本文件夹中的 zotero-unified-translator.xpi（当前为 1.0.1）。
4. 按提示重启，然后打开一个 PDF，选中一句文字尝试翻译。

设置入口：Zotero 主菜单「编辑 → 设置」左侧的 Zotero Unified Translator。在文献列表中对条目/PDF 右键打开「ZUT」子菜单；打开 PDF 后，也可在页面或选中文字上右键看到「翻译整篇 PDF」。

只用划词翻译不用安装 Python。整篇 PDF 翻译还需后端，完整安装、启动与使用方法见项目根目录 [README](../README.md)。
